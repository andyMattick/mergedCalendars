    Planner Help
    Quick guidance for setup and daily use.

    Welcome to Your Digital Planner

    This tool helps you plan classes with rotation days, units, notes, and assessments — all saved locally in your browser.

    New User Quick Start

    Do you want to start with the default Wesleyan calendar?

    Enter the same setup details used in the Custom Calendar sidebar section.
    This pre-fills settings and opens the right setup path.
    • Enter class names in the left sidebar
    • Create units with length and daily topics
    • Click any day on the calendar to add notes or mark tests
    • Switch divisions / semesters using the header selector
    • Use Backup / Restore or Profiles to keep your work safe

    Units & Pacing

    Units automatically calculate pacing on the calendar.

    • Add a unit with a name and length (in days)
    • Use Edit Days to set topics, quizzes, and tests for each day
    • The calendar shows unit name + progress (e.g. Day 4/10)
    • Max days are calculated from the start of the semester (Unit 1) or the next available day after the previous unit ends
    • You can shift a single unit or that unit + all following units

    Snow Days & Shifting

    To adjust for snow days or pacing changes:

    • In the unit list, use +1 Day (Snow) or -1 Day
    • Choose whether to shift only that unit or that unit + all following units
    • You can also open the Snow Day picker to select specific missed day numbers
    • The app warns you if a test would land on a No-Test day

    Special Days & Multiple Tags

    You can add multiple special tags on the same day (e.g. Chapel + Parent Night).

    • Open a day → enable Special Day and add a label / badge / color
    • Special days automatically block tests (you can override per period)
    • Use the Toggle All Special Tags button to show or hide them on the calendar

    Notes & Assessments

    • Click any day → add per-period notes and a general day note
    • Mark TEST TODAY for individual periods
    • Mark NO TEST TODAY for the whole day
    • Unit-planned tests and manual tests both appear in the Assessments Overview
    • Copy/Paste Day lets you quickly reuse notes from another day

    Printing & Export

    Use Print with Filters for a clean, printable calendar.

    • Filter by month, period, and unit
    • Includes class notes, special tags, and “NO TEST” flags
    • Shows the full weekday name (Monday, Tuesday, etc.)
    • Two-column layout for easier printing
    • Export Tests/Quizzes by Class opens an Assessments Overview you can print or copy

    Backup & Profiles

    • Backup Data — downloads a .json file of the current division
    • Restore Data — loads a previous backup
    • Auto-backup runs every 5 minutes (see the status badge in the bottom-right)
    • Profiles let you keep separate setups (different teachers, years, or divisions)
    • Switch profiles from the header dropdown
